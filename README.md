# XogTamar AI

**Turn your data into meaningful insights.**

A portfolio sample of a spreadsheet analytics application for solar, electrical, and general business data. Developed with AI coding assistance using Next.js, TypeScript, Python, FastAPI, Pandas, and local Ollama.

This repository contains selected source files and a small runnable Python example. It is not the complete application. The calculations in this sample run locally without an account, API key, hosted backend, or language model.

[View the public interface demo](https://xogtamar-ai.netlify.app/)

The website is a synthetic-data demo. Online file uploads and live AI inference are not enabled. The sample below runs independently of that website.

## What the project does

The full local application imports CSV and Excel workbooks, previews rows and columns, identifies missing data, computes statistics, offers chart choices, and exports Excel reports. A local language model can suggest a bounded analysis plan; Python calculates the numerical answer. Supported calculated columns include profit and profit margin with explicitly chosen input fields.

The main design decisions are:

- Preserve original uploaded files and work with derived data separately.
- Compute numerical answers with deterministic functions rather than generated code.
- Report missing values and excluded time intervals.
- Require explicit power units and timestamps for energy calculations.
- Bound spreadsheet size and preview dimensions to suit a modest Windows computer.
- Keep local inference optional so ordinary calculations work without a model.

## Run on Windows

Use Python 3.13. In PowerShell, open this repository folder and run:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_sample.py
.\.venv\Scripts\python.exe check_sample.py
```

Dependency installation needs internet access. Subsequent sample calculations run locally. Activating the environment is optional; these commands use its Python executable directly.

The demo prints JSON. The synthetic solar column has four valid values and one missing value; its average is **1,300 W**. Only one adjacent one-second interval can be integrated with the two-second maximum-gap setting, yielding **0.00030555555555555555 kWh**. The result marks the coverage as partial and reports the excluded intervals. This tiny number is intentional: power is not the same as energy.

The general sample's average revenue is **1,143 source units**. No currency is inferred.

## Frontend sample

`samples/analysis-chart.tsx` documents how the application presents verified chart data and lets users change the view. It requires an existing React/TypeScript app with `recharts` and `lucide-react`, the application's chart styles, and Python-precomputed chart payloads. Those supporting application files are deliberately omitted. The Python sample does not require Node.js.

## Scope and status

This portfolio demonstrates selected implementation work, not a deployed multiuser analytics service. The complete local application also uses FastAPI, PostgreSQL (or a native SQLite fallback), optional Ollama, and an example n8n workflow. Those services are not included here. A cloud backend/storage adapter has been prepared in the main project but has not been deployed.

The sample does not include uploads, credentials, databases, backups, model weights, or the complete frontend/backend. It has no deployment workflow and does not provision paid services. No open-source license has been selected for these source samples.
